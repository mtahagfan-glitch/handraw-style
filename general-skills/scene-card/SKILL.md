# بطاقة مشهد

أنشئ الملف في `storyboards/scene-<NN>-shot-<NN>.md` بهذا القالب، واملأ كل حقل قبل أي توليد. اسأل المالك فقط عن الحقول التي تغيّر النتيجة فعلًا.

```
# مشهد <NN> / لقطة <NN>
- وظيفة اللقطة: (Hook / Setup / Escalation / Reveal / Aftertaste)
- النص المنطوق:
- ملف الصوت النهائي: audio/final/...
- الانفعال:
- الفعل الرئيسي:
- حركة اليدين / الرأس / العينين: (من "توقيع الحركة" في brand-bible)
- حركة الكاميرا: (بسيطة: ثابتة، دفع بطيء، سحب بطيء)
- المكان والإضاءة:
- المرجع المستخدم: character/references/...
- يلزم lip-sync؟ نعم/لا
- المدة (ثوانٍ):
- معايير القبول:
- نتيجة المراجعة: (تُملأ بعد quality-check)
```

القواعد: لقطة قريبة أو متوسطة أولًا، لا حركات سريعة ولا التفاتات حادة ولا أصابع معقدة، والنصوص والشعار تُضاف لاحقًا في المونتاج.
